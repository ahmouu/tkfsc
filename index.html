數據維護

5 分鐘完成 Google Sheets 雲端連動

按照以下步驟，能將此網頁資料「一鍵」完美同步到您的 Google 試算表

  1. 建立一個新的 Google 試算表。
  2. 在選單點擊 「擴充功能」 > 「Apps Script」。
  3. 將編輯器內的預設程式碼全部刪除，並貼上以下程式碼： 
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var payload = JSON.parse(e.postData.contents);
  var action = payload.action;
  
  if (action === "sync") {
    var data = payload.data; // 接收的陣列資料
    
    // 清除舊資料並重寫表頭
    sheet.clear();
    sheet.appendRow(["編號", "產品/設備型號", "序列號", "保養到期日", "狀態", "備註", "更新時間"]);
    
    // 寫入數據
    for (var i = 0; i < data.length; i++) {
      var item = data[i];
      sheet.appendRow([
        item.id,
        item.model,
        item.serialNumber,
        item.warrantyDueDate,
        item.status,
        item.remark,
        new Date()
      ]);
    }
    
    return ContentService.createTextOutput(JSON.stringify({
      success: true, 
      count: data.length
    })).setMimeType(ContentService.MimeType.JSON);
  }
  
  return ContentService.createTextOutput(JSON.stringify({
    success: false, 
    error: "未知操作"
  })).setMimeType(ContentService.MimeType.JSON);
}
  1. 點擊頂部的 「部署」 > 「新增部署」。
  2. 選取類型為 「網頁應用程式 (Web App)」。
  3. 設定：
    • 將「誰有權限存取」設定為 「所有人 (Anyone)」。
    • 將「執行身分」設定為 「我 (您的帳戶)」。
  4. 點擊「部署」，授權 Google 存取（點擊「進階」並前往該腳本）。
  5. 複製產生的 「網頁應用程式網址 (URL)」 並貼到左側系統設定的對應欄位中，按下儲存！
